مسطرة الإصدارات

مقارنة خمسة إصدارات من pakmap على خمسة محاور: موثوقية، أداء، أمان، تجربة، وشفافية. كل رقم هنا مأخوذ فعليًا من عدّادات الاختبارات في الوسوم، وسعات أصول GitHub releases، وميزانيات التشغيل الموثقة — ومعادلات الدرج مكشوفة أدناه، وأوزانها بيدك.

الإصدار الحالي v0.9.2 اختبارات 189 e2e 36 فحوص a11y 12 · صفر مخالفات سقف الحجم ≤ 10M · 9.48M منفذ · بواب الإصدار ينفذ

انقر أي إصدار ليبرز حده في الرادار وفي كل بطاقة محور — والأوزان منطقية مستقلة لا يغيّرها النقر.

درجتك أنت — ووزن كل محور

الدرجة الكلية = مجموع (درجة المحور × وزنه). حرك المنزلقات لتضع ما يهمك أنت؛ كل شيء يعاد حسابه فورًا وبدون أي إرسال — الحساب كله في هذه الصفحة.

v0.7.0 · نواة الطرفية

CLI + TUI · 164 اختبار Rust
  • بحث وتثبيت وإزالة وترقية وتنظيف وتحديث كاش — لمسة مستخدم واحدة عبر libalpm.
  • readonly + تأكيد قبل الأوامر الخطرة (أصل الأمان).
  • مراجعة PKGBUILD داخل TUI — الأصل الذي لحق به الـ GUI لاحقًا.

v0.8.0 · وُلدت الواجهة

GUI · 172 Rust + 32 e2e + 23 vitest · 12 فحص a11y
  • بحث متدرّج (repo → AUR → Flatpak) يرسم الـrepo أولًا مع حارس أجيال وواجهة تُلغي الزائد.
  • عمليات بتأكيد + تقدم + إلغاء، أخبار وتحديثات وإحصاءات، وسمات light/dark/system.
  • التحقق من أسماء الحزم في Rust (validate_name) + عقد boot-smoke صاحي المحتوى (واة exit 3 عند واجهة معطلة — أُصحح وأُعيد وسمه بعد اكتشاف عيب في أول تاربول).
  • بدأت تكلفة الواجهة: أول ظهور انتظار أعمى ~1.1s (تهيئة webkit) بلا أي إشارة.

v0.9.0 · الوعي والأمان الحدودي

183 Rust + 35 e2e · واجهة منفذة 9.48M
  • تراي نظامي بشارة تحديثات، يفشل بأمان عند غياب libayatana-appindicator (catch_unwind).
  • فتح روابط الحزم بعد تحقق Rust: https فقط، حظر بيانات الاعتماد والمحارف الضابطة (CRLF) وسقف 2048B — ويُسجَّل {الاسم، المضيف} فقط.
  • مراجعة PKGBUILD داخل الواجهة (cache-first + جلب محدود 60s) — display-only بلا زر بناء.
  • CSP صارمة مع كعب التمرير مضروبًا بهاش، وطلّة ترقيق: vite devUrl بلا custom-protocol = باب شبح اكتُشف وأُغلق بعقد الـ smoke.

v0.9.1 · الإصدار الحالي — الشفافية أولًا

185 Rust + 36 e2e + 28 vitest · واجهة منفذة 9.49M
  • لا فشل صامتًا: أخطاء AUR تصل بواجهة إنسانية ("AUR RPC unreachable (offline?)"، HTTP n…) وعقد fail-open لم يُمس.
  • شارة «AUR checked Xm ago» — الأرقام تعلن عن عمرها.
  • splash للإطلاق البارد: هوية + مؤشر تقدم فورًا (~0.2s) بدل نافذة فارغة، وحارس Rust كاشف يمنع «نافذة تختفي للأبد».
  • إبراز PKGBUILD عبر محلّل بلا اعتماديات بعقد عدم الفقدان: الألوان لا تغيّر بايت واحد مما تراجعه.

v0.9.2 · الإصدار الحالي — بوابات لا ميزات

189 Rust + 36 e2e + 28 vitest · ميزانية أول IPC 3s مفروضة
  • بوابة الحجم عطلت الاصدار: تجاوز سقف 10M (عشريًا) يفشل الإصدار عند البواب — لا ينشر ولا يُمرَّر.
  • exit 4: أول IPC بعد ميزانية 3s = فشل صريح؛ عقد الـ smoke يعلن تدهور التشغيل بدل حمله بصمت.
  • بلا هدر بناء: أول بناء -p pakmap فقط — الواجهة لا تُصرَّف مرة بلا ميزة ثم مرة معها.

الأرقام الخام — مصدر كل ما فوق

مقاييس منفذة/مكتتبة لكل إصدار — كل قيمة قابلة للتشغيل أو الإعادة من الوسوم والمستودع. التمرير الأفقي بالسحب أو بأسهم لوحة المفاتيح داخل المستقبل متاح.
