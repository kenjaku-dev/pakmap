مسطرة الإصدارات

مقارنة سبعة إصدارات من pakmap على خمسة محاور: موثوقية، أداء الإقلاع، أمان، تجربة، وشفافية. كل رقم هنا مأخوذ فعليًا من عدّادات الاختبارات في الوسوم، وسعات أصول الإصدارات المستخرجة من التاربولات المنشورة نفسها، وميزانيات التشغيل الموثقة — ومعادلات الدرج مكشوفة، وقوائم البناء تحمل تاريخ دخول كل بند، وأوزانها النهائية بين يديك.

الإصدار الحالي v0.9.4 اختبارات Rust 242 e2e 36 vitest 35 فحوص a11y 12 · صفر مخالفات سقف الحجم 10,000,000 B · منفذ 9,982,368 · البوابة مفروضة

انقر أي إصدار ليبرز حده في الرادار وفي كل بطاقة محور — وشارة الدلتا تحت كل حلقة تعلن كم فحصًا وأيّ كام بايت تقدّم هذا الإصدار عن السابق.

v0.7.0 نواة الطرفية

2026-10-16 · CLI + TUI · 164 اختبار Rust
  • بحث وتثبيت وإزالة وترقية وتنظيف وتحديث كاش — لمسة مستخدم واحدة عبر libalpm.
  • readonly + تأكيد قبل الأوامر الخطرة (أصل الأمان) — وعبارات إنسانية لا أكواد (أصل الشفافية).
  • مراجعة PKGBUILD داخل TUI — الأصل الذي لحق به الـ GUI لاحقًا.

v0.8.0 وُلدت الواجهة

2026-10-18 · 172 Rust + 32 e2e + 23 vitest · 12 فحص a11y
  • بحث متدرّج (repo → AUR → Flatpak) يرسم الـrepo أولًا مع حارس أجيال وواجهة تُلغي الزائد.
  • عمليات بتأكيد + تقدم + إلغاء، أخبار وإحصاءات، وسمات light/dark/system.
  • عقد boot-smoke يعلن واجهة ميتة بدل نجاح كاذب (exit 3 — أُصحيح وأُعيد وسمه بعد اكتشاف عيب في أول تاربول).
  • بدأت تكلفة الواجهة: أول ظهور انتظار أعمى ~1.1s (تهيئة webkit) بلا أي إشارة.

v0.9.0 الوعي والأمان الحدودي

2026-10-27 · 183 Rust + 35 e2e · واجهة منفذة 9,937,024 B
  • تراي نظامي بشارة تحديثات، يفشل بأمان عند غياب libayatana-appindicator.
  • فتح روابط الحزم بعد تحقق Rust: https فقط، حظر بيانات الاعتماد والمحارف الضابطة وسقف 2048B — ويُسجَّل {الاسم، المضيف} فقط.
  • مراجعة PKGBUILD داخل الواجهة (cache-first + جلب محدود 60s) — display-only بلا زر بناء.
  • CSP صارمة مع كعب التمرير مضروبًا بهاش، وطلّة ترقيق: vite devUrl بلا custom-protocol = باب شبح اكتُشف وأُغلق بعقد الـ smoke.

v0.9.1 الشفافية أولًا

2026-10-27 · 185 Rust + 36 e2e + 28 vitest · واجهة منفذة 9,947,480 B
  • لا فشل صامتًا: أخطاء AUR تصل بواجهة إنسانية ("AUR RPC unreachable (offline?)"، HTTP n…) وعقد fail-open لم يُمس.
  • شارة «AUR checked Xm ago» — الأرقام تعلن عن عمرها.
  • splash للإطلاق البارد: هوية + مؤشر تقدم فوريًا (~0.2s) بدل نافذة فارغة، وحارس Rust كاشف يمنع «نافذة تختفي للأبد».
  • إبراز PKGBUILD عبر محلّل بلا اعتماديات بعقد عدم الفقدان: الألوان لا تغيّر بايت واحد مما تراجعه.

v0.9.2 بوابات لا ميزات

2026-10-29 · 189 Rust + 36 e2e + 28 vitest
  • بوابة الحجم تعطل الإصدار: تجاوز سقف 10,000,000 B يفشل الإصدار عند البواب — لا ينشر ولا يُمرَّر.
  • exit 4: أول IPC بعد ميزانية 3s = فشل صريح؛ عقد الـ smoke يعلن تدهور التشغيل بدل حمله بصمت.
  • بلا هدر بناء: أول بناء -p pakmap فقط — الواجهة لا تُصرَّف مرة بلا ميزة ثم مرة معها.

v0.9.3 تحصين وبوابات نشر

2026-10-31 · 236 Rust + 36 e2e + 35 vitest · واجهة منفذة 9,982,368 B
  • بوابة الروابط صارت شريطًا واحدًا: أخبار الحزم وحزمها عبر بوابة open_package_url نفسها، والروابط غير الآمنة تُعطَّل داخل شاشة الأخبار، والمحاكي في E2E يعكس الظرف invalid_url.
  • تثبيت وتحميل آمنان: install.sh بتحميل https-only وتحقق من مظفرة الأصول، وسقوف على كل أجسام الشبكة (تدفقات AUR)، وإغلاق ثغرة إعادة توجيه wget.
  • نشر fail-closed: حارس AUR قبل الوسم + SECURITY.md + عقد نسخة واحدة عبر version-sync — وSHASUMS256.txt صار أصل إصدار معلنًا.
  • معركة السقف: بناء كشف 10,134,344 B → جذر السبب (شجرة toml::Value سحبت رفقاء serde إلى الوصلة) → إصلاح استرجع ‎−122KB‎ → معايرة محاكاة → نفذ 9,982,368 (‎+17.6KB‎ تحت البوابة).

v0.9.4 الآن تنظيف بضمانات

2026-11-01 · 242 Rust (217 CLI/lib + 25 GUI) + 36 e2e + 35 vitest
  • تنظيف حقيقي، ضمانات أكبر: واجهة SourceBackend ومكيِّفُها FlatpakBackend حُذفتا (استعمال Flatpak وحيد)، وآخر allow(dead_code) في المستودع زال.
  • ممر pager واحد: pager_plan/show_in_pager أبدلا كتلتين مفترقتين في مُثبِّت AUR — spawn واحد مفروض باختبار حارس، وForeignOwner تسمية تخبر أن الحارس يفحص مالكًا لا مجلدًا.
  • العقد المنشور صار اختبارًا: ملف حالات مشتركة (33) تقرؤه شيفرة Rust وقيمات vitest معًا — البوابة هي المرجع، وأربعة انحرافات في المحاكي أُغلقت أولًا (قياس البايت، تطبيع الشرطات العكسية، المضيف الغائب، محارف المضيف الممنوعة).
  • صفر بايت تغيَّر في المنفذ: البايت نفسه في الوسمين (9,982,368) — fat LTO استوعب التنظيف؛ ومراجعة على محورين (معايير/مواصفة) جلست إصلاحاتها المجرّبة — إصدار تنظيف كما وُعد.
